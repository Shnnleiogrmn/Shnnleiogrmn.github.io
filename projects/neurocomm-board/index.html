NeuroComm Board Converter

Embedded Systems Project / Proposal

A microcontroller-based assistive communication board for people with aphasia, using accessible physical buttons and immediate pre-recorded voice output.

01 Overview 02 Problem & design focus 03 Proposed system 04 Hardware & technologies 05 Proposed interaction process 06 Current status

01 — CASE STUDY

Overview

NeuroComm Board is an embedded assistive communication proposal for individuals with aphasia who may find it difficult to express everyday needs verbally. Large, color-coded physical buttons represent common requests; pressing a button triggers its corresponding pre-recorded voice message.

The design focuses on an alternative way to express common needs, with clear controls and immediate feedback.

02 — CASE STUDY

Problem & design focus

Everyday requests should be easy to express without navigating a complex interface. The proposed design focuses on clear choices, accessible physical controls, immediate feedback and a straightforward interaction.

04 — CASE STUDY

Hardware & technologies

Core controller
Arduino Uno R3
Input
8 large push buttons
Visual feedback
8 LEDs
Audio
DFPlayer Mini MP3 Module
Storage
MicroSD Card
Output
3W / 4–8Ω Speaker
Logging
Arduino built-in EEPROM
Power
USB for testing; 5V adapter or power bank for portable use

Optional enhancements

I2C LCD, buzzer, rechargeable battery module and DS3231 RTC. These are optional additions, not established core components.

05 — CASE STUDY

Proposed interaction process

  1. A physical button is pressed.
  2. Arduino reads the input and handles debounce.
  3. The corresponding LED activates.
  4. Arduino sends the audio command.
  5. DFPlayer Mini plays the stored voice message through the speaker.
  6. The event is recorded in EEPROM.
